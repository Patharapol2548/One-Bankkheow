Project Highlights

Core capabilities built into the application.

Catalog & Filter

Instant search and categorization across different needle types (Embroidery, Beading, Leather, Tapestry).

Live Currency Proxy

Backend currency exchange proxy that converts THB (฿) to CNY (¥) in real-time on product pages.

Interactive Cart

Stateful shopping cart with quantity modifications, stock validation, and subtotal calculation.

Multi-Step Checkout

Select existing delivery addresses or add new addresses dynamically during checkout.

Admin Inventory CRUD

Secure admin portal to create, modify, inspect, and remove products from the database.

Docker Compose Ready

Complete orchestration connecting MySQL 8.0 with pre-loaded seed SQL, Express 5 backend, and Nginx frontend.

Technical Architecture

The system follows a clean 3-tier architectural separation:

1. Frontend Layer
  • • HTML5 / JS (Vanilla)
  • • Tailwind CSS
  • • Served by Nginx (:5500)
2. Backend API
  • • Node.js & Express 5
  • • RESTful routing (:3100)
  • • CORS & Auth middleware
3. Persistence
  • • MySQL 8.0 (:3307/3306)
  • • Schema: itcs223_store
  • • Volume persistent storage
