One Bank Kheow Store

"One Green Banknote" — Affordable Fixed-Price E-Commerce Platform

Based on the popular Thai "20 Baht Shop" concept (Thailand's green 20-Baht banknote), our platform digitizes neighborhood retail into a scalable e-commerce store with centralized inventory management, dynamic currency exchange (THB↔CNY),customer carts, and administrative controls.

3-Tier Technical Architecture

Technical Architecture

The system implements a decoupled 3-tier architecture for clean separation of concerns:

1. Frontend Layer
  • • HTML5 / JS (Vanilla)
  • • Tailwind CSS
  • • Port :5500
2. Backend API
  • • Node.js & Express 5
  • • RESTful routing (:3100)
  • • CORS & Auth middleware
3. Persistence
  • • MySQL 8.0 (:3307/3306)
  • • Schema: itcs223_store
  • • Docker volume storage

How to Run the Project

Choose between the automated 1-click launcher or manual setup.

Recommended for Evaluators Docker-Powered

Option 1: 1-Click Launch

Starts MySQL 8.0 (auto-importing sample data), Node.js backend, and frontend web server, then opens your browser automatically.

1
Open Docker Desktop Make sure Docker is running on your PC.
2
Double-click START.bat Located in the root folder (or inside run/START.bat).
3
Ready! Browser Opens Storefront opens at http://localhost:5500.
🛑 Finished testing? Double-click STOP.bat to shut down all containers cleanly.
Developer Setup Native Node.js & MySQL

Option 2: Manual Setup

Run services individually on your host machine without Docker:

Step 1: Database

Import schema and sample data into your MySQL server:

mysql -u root -p < OneBankKheowStore-Back-End-main/data/onebankkheow.sql
Step 2: Backend API (:3100) cd OneBankKheowStore-Back-End-main
npm install
npm start
Step 3: Frontend Web (:5500)

No build step needed. Serve static HTML:

npx serve OneBankKheowStore-Front-End-main/html -l 5500
💡 Shortcut: You can also run run\start-backend.bat and run\start-frontend.bat.
